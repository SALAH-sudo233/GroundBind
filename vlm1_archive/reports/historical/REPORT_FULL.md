# V-SIGHT Agentic 竞争探针缓释框架：完整报告

**日期**：2026-09-27  
**状态**：已实现、已在 13 个上游 VLM 上完成评测。GT 框路径与上游预测框路径均有结果。  
**一句话**：给一个零训练的开源验证器追加一次「对立关系」提问，用两次打分的差值判断关系是否成立；在 13 个上游 VLM 上把 relation 幻觉框的抓获率从 20.6% 提到 27.5%，CBR 从 34.3% 降到 31.0%，定位质量无损。

---

## 1. 问题与动机

V-SIGHT 的核心观察是 **ROH（attribute + relation）系统性难于 BOH（object + co-occurrence）**。这个差距在本项目里已跨多个层级独立复现：验证器层、11 模型层、agentic 过滤器层。其中 relation 是最顽固的一类。

已被证伪的方向（不再重复）：

| 方向 | 判据 |
|---|---|
| 换证据形式（画参考框 / 文本参考） | E2d delta −0.025、E2e AUROC 0.566，与不给参考无差异 |
| 换决策头（引导式推理 / 上游自检） | 全部 ≤ LoRA-3B flat 0.656，只是整体压低 P(yes) |
| 换 LoRA 配方 / 加人工 binding 标签 | R4/R5 双负结果，8000 条人工标签仍 100% 镜像 |
| 便宜信号（GroundingDINO 检测器） | relation AUROC 0.51–0.55 ≈ 随机 |
| CCV 做过滤或给框 | 691 负样本只丢 8 个；修正框 mIoU 0.3924→0.3056 |

共同点：**都在改「怎么判断」，没有改「判断什么」。** 根因诊断指向 relation-contradiction 信号饥饿（E6 训练集 CONTRADICTED 仅 19/7521）。

本框架换思路：**不改验证器，改提问内容**。既然「这个框里是不是 X 在 Y 后面」难判，那就再问一次「这个框里是不是 X 在 Y 旁边」——如果对立关系得分更高，原关系就不成立。

## 3. 框架

```
查询 + 上游预测框
      │
      ├─ OmniVerifier 给原表达打分                    → z0     [1 次前向]
      │
      ├─ 探针库：能否解析出合法对立关系词？
      │     否 → 结束，用 z0 判决（BOH 三类走此路）
      │     是 ↓
      ├─ OmniVerifier 给至多 2 个对立表达打分          → z_c1, z_c2  [+1.2 次]
      │
      ├─ gap = max_i(z_ci) − z0
      │
      └─ 决策头（fold A 拟合）：keep = f(z0, gap) ≥ τ
             gate：只在探针实际覆盖的行用新决策，其余沿用单臂
```

### 3.1 探针构造（确定性模板，无 LLM 参与）

约束：目标角色不可交换（`the man holding a bag` 不得改写成 `the bag held by the man`）；最长短语优先（`on top of` 先于 `on`）；歧义谓词回退（裸 `on` 一词多义 → 不生成探针）；无自动反义词词典，只用审计过的对立表。

**核心设计原则：对立词必须是构型词，不是距离词。** 实测（`next to` 行，n=191）：

| 候选对立词 | AUROC |
|---|---|
| `far from` | **0.4369（反信号）** |
| `away from` | 0.4315（反信号） |
| `behind` 单独 | 0.5860 |
| **垂直/深度族取 max** | **0.7453** |

`next to` 是构型陈述（在旁边、同一层）而非距离陈述。语料佐证：`far from`/`away from` 在 relation 500 组中正例出现 **0 次**、负例 4 次。典型例子 `the couch next to the TV → the couch under the TV`——沙发**仍然紧邻**电视，被改的是垂直关系，所以问「是否远离」两边都答否（实测负例 19/21、正例 147/177 都判否）。

### 3.2 三类探针只保留 competitive

| 探针类型 | AUROC | 处置 |
|---|---|---|
| **competitive**（换对立关系词） | **0.7781** | 采用 |
| weakened（删关系从句） | 0.6881（同子集原表达 0.6861） | 关闭，无增量 |
| equivalent（保守改写） | **0.4398** | 关闭，反信号 |

`weakened` 只确认物体存在：负例 `the person standing next to the table` z=−5.25 → 探针 `the person` **+9.875**。`equivalent` 方向相反（措辞敏感反而相关于正例），与原方案假设不符。

### 3.3 只在 relation 触发

GT 框路径分 htype 拟合后，`gap` 权重符号相反：

| htype | gap 权重 | A2−B1 | 判定 |
|---|---|---|---|
| object | **+0.418** | −0.0002 | 不显著 |
| co_occurrence | **+0.334** | +0.0032 | 不显著 |
| attribute | **+0.283** | +0.0041 | 不显著 |
| **relation** | **−0.673** | **+0.0282** | **显著** CI[+0.0074,+0.0488] |

池化拟合会让它们互相抵消（−0.053），信号被抹平。道理也直白：另三类负例改的是主体词或属性词（chair→table、red→blue），关系词没动，换关系词问不到点上。

### 3.4 判别机制

学到的权重里 `gap` 系数为负且绝对值远大于 `z0`（如 −0.903 vs +0.142）。**判别力来自「对立关系得分更高」这个差值，不是原表达的绝对分数。**

实例：负例 `the laptop under the orange table`，原表达 z=+2.375（验证器误判成立），竞争探针 `on top of` 得 **+5.750** → 差值立刻暴露矛盾，单看 +2.375 判不出来。

## 6. 两个必须避开的陷阱（都是本轮踩出来的）

### 6.1 `probed` 分组位是 oracle 泄漏

第一版把「是否被探测」当特征，得到 ALL FGR 13.03% / BOH 5.07%，比现在好看。**但那不可引用。**

因为收集探针时用了 `ht=='relation' or role=='positive'` 筛选，这一位编码了真实 `hallucination_type` 和极性：

| probed | 正例 | 负例 | 正例率 |
|---|---|---|---|
| 1 | 3604 | 3186 | **0.531** |
| 0 | 2578 | 12207 | **0.174** |

三倍差。按项目协议 htype 只能在 evaluator 里分层。去掉泄漏后结果**反而更强更干净**（−10.15pp / 13/13，带泄漏版的 A2−B1 只有 −0.11pp 不显著）。

**通用教训**：任何「是否触发/是否适用」指示位，先查它的正例率是否跳水；若跳水就是筛选条件泄了标签。限定在「指示位恒为 1」的子集内比较是最简单的除泄法。

### 6.2 加新特征会移动全局阈值，污染特征恒为 0 的子群

不 gate 直接把 `[z0, gap]` 用于全部行：

| 臂 | object | co_occurrence | attribute | relation |
|---|---|---|---|---|
| B1 | 2.6% | 13.6% | 15.3% | 34.3% |
| A2 未 gate | 2.7% | **14.6%** | **16.7%** | 31.8% |
| 模型级 Δ | +0.11pp | **+1.01pp 显著变差** | **+1.40pp 显著变差** | −2.47pp |

机制：`gap` 在无探针类恒为 0，但加入该特征后 `tau` 会移动（visual-rft 0.3048→0.2601、Qwen3-VL-8B 0.3630→0.3248），这些类的分数整体平移后拒绝率暴跌（visual-rft attribute 31%→8%、Vision-R1 26%→13%）。

**正解 = gate**：探针只改它实际覆盖的行。gate 后另三类逐位不变（0.00pp、0 行变动），是严格加法。

## 8. 限制

1. **无泄漏主表的分母是探针覆盖子集**（每模型约 120–164 个 relation 负例），不是完整 2000/500。不能与官方口径表混排。
2. **relation 绝对值仍高**（A2 后 FGR 29.37%、CBR 31.0%，仍是四类最高）。方法显著改善但远未解决 relation 幻觉。
3. **小 n_c 模型不可与大 n_c 并列**：fold B 内 UniVG-R1 n_c=17、visual-rft n_c=13，其 relation CBR 无变化很可能只是样本太少。
4. **谓词偏深度/垂直关系**。左右关系在本 benchmark 仅 0.65%（13/2000 组），`holding`（84 行）无审计对立词。镜像等变类方法在此无输入。
5. **词先验在此 benchmark 上异常强**：纯谓词对数似然比（不看图、不调模型）在 GT 框 relation 上 AUROC **0.8475**，高于 Omni 单臂 0.7441。本方法未使用该特征，但任何 relation 结论都应附此对照，否则无法排除语言捷径。
6. **只覆盖 DG (t2)**。GG (t4) 的过滤器输出不存在，不能把 DG 结论声称为两任务结果。
