This compact mirror contains the same 15-photo, two-model illustrative run.
300 upstream JSON records, 300 mean-layer/head/token image-attention grids, 300 new Omni/JEV verifier records and 105 actual independent Omni mean-head grids, frozen ASV policy and four representative PNGs.
Full raw token/head NPZ, original photographs, fonts and budget raw NPZ archives are preserved in the separate desktop browser package; none are included here.
All mean grids derive directly from saved real attention tensors, with source raw SHA256 and selected output-token indices. No bbox-derived heatmaps. The compact export includes source-record SHA256, source full-raw NPZ SHA256, actual selected emitted-token indices and IDs. Use --verify to recompute all 405 compact means exactly from the complete desktop raw tensors.
Blue visualization maps are relative to each grid mean, with pooled 95th-percentile color clipping; colors do not compare absolute attention across models.
Generation metadata is not an update to the paper main evaluation. ASV filters the same fresh candidate, with no upstream attention change.
The scripts expect the complete desktop experiment root for rerendering; photographs and full raw tensors intentionally are not in Git. Times New Roman is optional from a user-provided local fonts directory, never installed or committed here.
